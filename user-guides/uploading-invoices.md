# Uploading Invoices

This guide explains how to add a new invoice to Keep Track.

## Two ways to add an invoice

### Option A: Upload it yourself

1. Go to the **Invoices** page using the sidebar.
2. Click the **Upload** button, or simply drag a PDF file from your computer and drop it onto the page.
3. Wait a few seconds while Keep Track reads the invoice automatically.

### Option B: Drop it in the watched folder

If your organisation has a shared network folder set up for this:

1. Save or scan the invoice PDF into that folder.
2. Keep Track checks the folder automatically and will pick up the new file within a short time.
3. It will then appear in your **review queue** — you'll still need to check it (see below).

## Checking what Keep Track found

Keep Track uses AI to read the invoice and fill in the details for you:

- Date
- Supplier (who the invoice is from)
- Amount
- Category (e.g. Electricity, Water, Supplies)
- Notes

**Always check these details carefully.** The AI does a good job most of the time, but it can make mistakes — especially with handwritten or unusual invoices.

1. You'll see the invoice PDF on one side of the screen and the details it found on the other.
2. Click into any field to correct it if needed.
3. If Keep Track thinks this might be a duplicate of an invoice you've already added, it will show a warning — check this before continuing.

## Confirming the invoice

1. Once everything looks correct, click **Confirm**.
2. If your organisation uses the signing feature, you'll be asked to sign the invoice first — see [Reviewing and Signing](reviewing-and-signing.md).
3. Once confirmed, the invoice is saved and will immediately show up in your dashboard totals.

## Tips

- You can upload invoices in any order — Keep Track sorts everything by date automatically.
- If you make a mistake after confirming, ask an Administrator or Standard user to correct it for you.
